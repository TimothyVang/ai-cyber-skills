# sharpen

**Use when:** a task should be deeper, not bigger, before rewriting its prompt.

1. Say what a top professional in this field would do here that the user isn't asking for.
2. Name the rawest material they'd start from instead of what's already been digested.
3. Name the specific methods and tools they'd use.
4. Say what, other than you or the user, would show the result is right (an external oracle: a test, a measurement, a spec, a real user).
5. Rewrite the prompt to ask for exactly that.

**Hard rule.** Leave the user's choices open instead of deciding them.

**Output:** the four answers, then the rewritten prompt.

**Done when** each of the four answers is concrete (a named method, tool, material, or oracle) and the rewritten prompt asks for each one.
