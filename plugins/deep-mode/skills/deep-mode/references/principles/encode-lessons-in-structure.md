# encode-lessons-in-structure

Group: meta. When: you write the same instruction a second time, or notice a recurring correction.
- **Rule.** Encode the rule as a lint, metadata flag, runtime check, type, or script instead of more text. Ladder (author's later guidance): architecture/data structures → lint or test → skill/rule → human review.
- If the lesson needs judgment and cannot be encoded, make the instruction more prominent and add an example of the failure mode.
- **Corollary.** If the fix is structural, use only the structural fix. The instruction is the symptom.
