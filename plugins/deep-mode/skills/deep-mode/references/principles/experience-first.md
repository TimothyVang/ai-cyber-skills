# experience-first

Group: core. When: product, UX, or feature-scope tradeoffs.
- **Rule.** When implementation convenience conflicts with user delight, choose delight.
- **Checks.** Every feature, control, and option is justified. Ship less, ship better. Prototype before committing (throwaway HTML is cheaper than production code). Get details right: transitions, alignment, spacing, feedback, error states. Every feature serves the core loop or gets out of the way.
- The user is whoever consumes the work: end user, the colleague importing the library, the next maintainer. Explain impact from their perspective.
- Foundational-thinking governs the *sequence*; this governs the *target*.
